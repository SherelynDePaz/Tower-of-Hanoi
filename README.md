# Tower of Hanoi (Prolog)

A Tower of Hanoi game where the puzzle logic is written in Prolog.

**Live Demo:** [Play here](https://sherelyndepaz.github.io/Tower-of-Hanoi-prolog/)

## Features
- Solver and move checking written in Prolog (`hanoi.pl`)
- Animated disks, undo, sound, light and dark mode
- Levels mode: Easy (3 disks), Medium (4), Hard (5) and Extreme (6), with timer and best scores
- "Solve with Prolog" plays the optimal solution step by step

## How it works
Prolog runs inside the browser using Tau Prolog, so no server is needed.
Tau Prolog is built into `index.html`, so the whole game is one file.

## Files
- `index.html`  the page, animation and Prolog engine
- `hanoi.pl`    the Prolog program (also embedded inside `index.html`)

## Run locally
Double-click `index.html`.
